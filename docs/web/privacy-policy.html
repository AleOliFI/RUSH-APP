RUSH

Política de Privacidade

Última atualização: 23 de junho de 2026

O RUSH ("nós", "nosso") respeita sua privacidade e está comprometido com a proteção dos seus dados pessoais em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).

1. Quem somos

RUSH é um aplicativo móvel de monitoramento da Variabilidade da Frequência Cardíaca (VFC/HRV) para atletas. Desenvolvido e operado por Ale Olifi, com sede no Brasil. Contato: afilho785@gmail.com

2. Dados que coletamos

2.1 Dados de conta

  • Endereço de e-mail (para autenticação via Supabase Auth)
  • Nome completo (opcional, para personalização da saudação)
  • Gênero e perfil hormonal (opcional, para ajuste do algoritmo)

2.2 Dados de saúde

  • Leituras de VFC (RMSSD) capturadas pela câmera do dispositivo via PPG
  • Frequência cardíaca em repouso (RHR)
  • Questionário de bem-estar diário (sono, estresse, fadiga muscular)
  • Data de início do ciclo menstrual (opcional, somente para usuárias femininas)
  • Dados de sessões de treino (duração, FC média, TRIMP estimado)

2.3 Dados de comportamento

  • Fatores diários registrados voluntariamente (álcool, sono ruim, viagem, etc.)
  • Streak e histórico de medições

2.4 Dados de pagamento

  • Processados exclusivamente pela RevenueCat (App Store / Play Store) e pelo Stripe. Nós nunca armazenamos dados de cartão de crédito.

2.5 Dados técnicos

  • Logs de erros (anônimos, via Supabase)
  • Versão do app e sistema operacional

3. Como usamos seus dados

  • Calcular seu escore de prontidão diária (E_Prontidão)
  • Gerar prescrições de treino personalizadas
  • Calcular baselines e tendências de VFC ao longo do tempo
  • Adaptar o algoritmo ao perfil hormonal (quando informado)
  • Sincronizar assinatura premium entre dispositivos
  • Enviar notificações push de lembrete de medição (somente se você autorizar)

4. Compartilhamento de dados

Seus dados de saúde nunca são vendidos ou compartilhados com terceiros para fins comerciais. Compartilhamos dados apenas com:

  • Supabase — banco de dados e autenticação (servidores na AWS us-east-1)
  • RevenueCat — gestão de assinaturas
  • Stripe — processamento de pagamentos
  • Autoridades legais — somente quando exigido por lei

5. Armazenamento e segurança

  • Todos os dados são armazenados com criptografia em repouso (AES-256)
  • Comunicação protegida por TLS 1.3
  • Acesso aos dados restrito ao próprio usuário via Row Level Security (RLS) no Supabase
  • Dados de saúde não são usados para treinamento de modelos de IA de terceiros

6. Retenção de dados

  • Dados de saúde são retidos enquanto sua conta estiver ativa
  • Ao excluir sua conta, todos os dados são apagados permanentemente em até 30 dias
  • Logs de erro são retidos por 90 dias e então deletados automaticamente

7. Seus direitos (LGPD)

Você tem direito a:

  • Acesso — solicitar uma cópia de todos os seus dados
  • Correção — corrigir dados incorretos ou desatualizados
  • Exclusão — apagar sua conta e todos os dados associados
  • Portabilidade — exportar seus dados em formato CSV (em breve)
  • Revogação de consentimento — retirar autorização de uso a qualquer momento

Para exercer seus direitos, entre em contato: afilho785@gmail.com

8. Câmera e permissões

O RUSH solicita acesso à câmera traseira exclusivamente para capturar o sinal PPG (luz refletida no dedo) e calcular a VFC. Nenhum vídeo ou imagem é gravado, transmitido ou armazenado. O processamento é feito localmente no dispositivo em tempo real.

9. Menores de idade

O RUSH não é destinado a menores de 18 anos. Não coletamos conscientemente dados de menores. Se você acredita que uma criança forneceu dados ao app, entre em contato conosco para remoção imediata.

10. Alterações nesta política

Podemos atualizar esta política periodicamente. Notificaremos você por e-mail ou notificação push em caso de mudanças materiais. A data de "última atualização" no topo reflete a versão vigente.
